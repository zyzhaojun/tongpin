# 同屏 0.2.1 使用说明

## 准备

适用于 Windows 64 位电脑。将 ZIP 在两台电脑上分别完整解压，双击文件夹中的 Tongpin.exe。请保持 exe 与其旁边的文件、文件夹放在一起。

两台电脑需位于可互相访问的局域网。笔记本可以用 Wi-Fi，大屏电脑可以用网线。软件运行时不需要互联网。当前版本仅共享画面。

## 大屏电脑

1. 打开程序，选择“接收投屏”。
2. 首次显示防火墙提示时，点击“一键修复”，在 Windows 管理员确认窗口中选择“是”。这个端口规则只允许同一局域网，且不受软件移动或升级影响。
3. 等待笔记本发起连接；核对设备名称和 IP 后点击“允许投屏”。若现场网络可信，也可勾选“自动允许下一台电脑（仅本次）”。
4. 对方开始投屏后，按 F11 全屏。Esc 退出全屏。要终止会话，点击“结束接收”或关闭程序。

全屏时只显示接收到的画面，Tongpin 的标题栏、按钮和状态栏都会隐藏。发送画面与大屏比例不同时会保留黑边，避免课件内容被拉伸或裁切。

## 专家笔记本

1. 打开程序，选择“我要投屏”。
2. 在“附近的大屏”中选择接收设备。没有出现时点击“重新查找”，或输入大屏显示的 IP 地址。
3. 等待大屏允许连接。
4. 选择整个屏幕，或将“显示”切换到“应用窗口”再选择窗口。
5. 点击“开始投屏”。PPT 放映建议选择整个屏幕，以便跟随独立的放映窗口。
6. 点击“停止画面”会保留当前配对，可直接重新选择画面；点击“断开连接”才会结束配对并使旧连接信息失效。

## 为什么还保留长连接信息

长连接信息是自动发现失败时的备用方式，同时包含设备地址、身份校验信息和随机密钥。日常使用无需复制它；只有跨网段且 IP 连接也不可用时，才考虑通过剪贴板或 U 盘传递。

待连接的信息每 10 分钟自动更新，投屏期间不受这一有效期限制。停止画面、切换窗口或调整画质不会更换连接信息；主动断开或网络在 60 秒内未恢复后，旧连接信息才会失效。

Wi-Fi 短暂中断时，两端会在 60 秒内自动尝试恢复，并在大屏上保留原发送电脑的位置。恢复期间无需重新粘贴连接信息。

## 常见问题

- **找不到设备**：先点击“重新查找”；仍未出现时输入大屏 IP。自动查找覆盖同一 `/24` 网段，访客 Wi-Fi 或校园网终端隔离仍可能阻止连接。
- **无法连接**：确认大屏已进入“接收投屏”，并检查防火墙卡片是否已经消失。接收信令默认使用 TCP 48765。
- **防火墙修复失败**：不要关闭整个防火墙。学校组策略可能禁止本机添加规则，请让管理员放行 TCP 48765，入站来源限定 `LocalSubnet`。
- **端口被占用**：同一台电脑只打开一个“接收投屏”实例。
- **连接成功但画面未出现**：发送端还需要选择屏幕并点击“开始投屏”。如果长时间没有画面，检查网络是否阻止 WebRTC 连接。
- **PPT 切换后没跟随**：选择“整个屏幕”。分享单个编辑窗口时，独立放映窗口不会自动包含进去。
- **窗口黑屏或停住**：保持被分享窗口打开且未最小化；可停止后改为分享整个屏幕。
- **画面卡顿**：重连时选择“流畅 · 720p”，优先使用信号良好的 5GHz Wi-Fi，大屏电脑可用网线。
- **不清楚选哪个地址**：选择与专家笔记本在同一局域网的地址，避开无关 VPN/虚拟机网卡地址。必要时由管理员确认。
- **没有声音**：本版本只共享画面，声音、麦克风均不采集。
- **下载程序提示未知发布者**：当前预览包尚未进行代码签名。请按学校规则处理，勿关闭安全软件。

底部显示实际分辨率、帧率、码率及网络往返时间。网络往返时间不是端到端画面延迟。静态课件的帧率下降通常正常。

## 使用前验证

首次在讲座现场使用前，用目标笔记本和大屏电脑试投课件，检查中文小字、鼠标、PPT 放映和停止功能，并连续运行一段时间。预览版仍需在你们的两台真实设备和校园网络上验收。
